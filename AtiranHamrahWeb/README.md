# Atiran Hamrah Web

نسخه وب اپلیکیشن «آتیران همراه» برای نمایش گزارش‌های مدیریتی با اتصال **مستقیم و فقط-خواندنی** به دیتابیس `Atiran2` روی SQL Server.

این نسخه یک وب‌سرور سبک Node.js است؛ چون مرورگر به‌تنهایی نمی‌تواند مستقیم به SQL Server وصل شود، سرور Node این کار را انجام می‌دهد و همان گزارش‌ها را در یک داشبورد لوکس و سه‌بعدی نمایش می‌دهد.

## امکانات

- اتصال مستقیم به دیتابیس: `37.143.147.19:1433` / `Atiran2`
- کاربر: `AdminAn`
- همه کوئری‌ها فقط `SELECT` — هیچ نوشتن/حذف/ویرایشی وجود ندارد
- داشبورد مدیریتی با:
  - کارت‌های KPI با آیکن‌های سه‌بعدی اختصاصی
  - نمودار رادار شش‌بُعدی
  - ستون‌های ایزومتریک سه‌بعدی
  - دونات چک‌ها (بانک / وضعیت)
  - رتبه‌بندی مشتری، کالا، ویزیتور و فاکتور
- رابط RTL فارسی، تیره و لوکس با گرادیان، شیشه و افکت سه‌بعدی
- **کاملاً واکنش‌گرا (Responsive)** برای اندروید و آیفون:
  - منوی کشویی موبایل (Drawer)
  - دکمه‌های لمسی حداقل ۴۴ پیکسل
  - شبکه‌های KPI سازگار با عرض گوشی
  - پشتیبانی از `safe-area` (نوار وضعیت / نوار پایین)
- گزارش‌های پیشرفته مدیریتی:
  - «مشتریان»: بدهی، اعتبار، پوشش ویزیتور
  - «کالاها و قیمت‌ها»: قیمت فروش، موجودی
  - «چک‌ها»: مبلغ، بانک، وضعیت
  - «بانک‌ها»: رتبه‌بندی و توزیع مبلغ چک بر اساس بانک
  - «فروش و فاکتورها»: روند فروش، مشتریان بر اساس فاکتور
  - «خرید و سود»: ارزش خرید، ارزش فروش، سود بالقوه، کم‌موجود / پرموجود
  - «موجودی انبار»: ستون سه‌بعدی موجودی انبارها
  - «ویزیتورها»: تعداد مشتری و مجموع بدهی هر مسیر
- برندینگ: Meelano Studio Design • Milad Yaghoobi

## اجرا

```bash
cd AtiranHamrahWeb
npm install
cp .env.example .env   # در صورت نیاز مقادیر را تغییر دهید
npm start
```

سپس در مرورگر باز کنید:

```
http://localhost:8080
```

### API

- `GET /api/health` → بررسی وضعیت اتصال
- `GET /api/dashboard` → همین‌ها: KPIs و لیست داده‌ها

## اجرا با Docker

```bash
cd AtiranHamrahWeb
docker compose up -d --build
```

سپس:

```
http://localhost:8080
```

## تنظیمات (`.env`)

| متغیر | پیش‌فرض |
|---|---|
| `PORT` | `8080` |
| `DEMO_MODE` | `0` (برای پیش‌نمایش داشبورد بدون دیتابیس مقدار را `1` کنید) |
| `DB_HOST` | `37.143.147.19` |
| `DB_PORT` | `1433` |
| `DB_NAME` | `Atiran2` |
| `DB_USER` | `AdminAn` |
| `DB_PASSWORD` | `St@R2022$` |

> اگر فایروال سرور اجازه اتصال از شبکه شما را ندهد، خارج از این برنامه است. پورت `1433` باید روی SQL Server فعال باشد (TCP/IP و SQL Server Browser در صورت نیاز).
